Python Assignment – Product Catalog Management

1. Project Overview

This project focuses on practicing fundamental Python concepts through product catalog management. It demonstrates how to store, organize, update, and process product information using Python's built-in data structures.

2. Tasks Included

Task 1: Product Collections (Lists and Tuples)

- Create a collection of product names.
- Store product details using tuples containing product name, price, and category.
- Access specific elements from lists and tuples.
- Add new products to a list.
- Understand how lists and tuples store data.

Task 2: Categories (Sets)

- Create a collection of product categories.
- Convert categories into a set.
- Understand how sets automatically remove duplicate values.
- Check whether a particular category exists in a set.
- Count the number of unique categories.

Task 3: Product Pricing (Dictionaries)

- Store product names and their prices in a dictionary.
- Add new products and update existing prices.
- Remove products safely.
- Calculate the average product price.
- Identify the highest-priced and lowest-priced products.

Task 4: Combined Operations

- Combine lists, tuples, and dictionaries to organize product information.
- Create a product catalog containing product names, prices, and categories.
- Group products according to their categories using a dictionary.
- Find the category containing the maximum number of products.
- Display all products belonging to that category.

3. Python Concepts Used

- Lists
- Tuples
- Sets
- Dictionaries
- Loops
- Conditional statements
- Dictionary methods
- Functions
- "len()" and "max()"
- Lambda functions
- Data manipulation and grouping

5. Requirements

- Python 3.x
- A Python editor such as Visual Studio Code

No external Python libraries are required for these basic data structure operations.

6. How to Run

1. Install Python 3 on your computer.
2. Open the project folder in Visual Studio Code or a terminal.
3. Run each task separately using the following commands:

python task1.py
python task2.py
python task3.py
python task4.py

7. Expected Learning Outcomes

After completing these tasks, the learner should understand how to use Python lists, tuples, sets, and dictionaries to manage product information, perform basic calculations, organize data, and solve problems using combined data structures.
